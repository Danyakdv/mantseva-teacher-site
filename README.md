# Персональный сайт педагога — Манцева О.А.

## Деплой на Railway

1. Зайдите на https://railway.app и войдите через GitHub
2. Нажмите "New Project" → "Deploy from GitHub repo"
3. Загрузите эти файлы в репозиторий GitHub
4. Railway автоматически определит Node.js и задеплоит
5. Получите URL вида: https://mantseva-site.up.railway.app

## Или деплой через CLI
```
npm install -g @railway/cli
railway login
railway init
railway up
```
